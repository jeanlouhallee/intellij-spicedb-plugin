# SpiceDB IntelliJ Plugin

Community plugin for [SpiceDB](https://github.com/authzed/spicedb) schema files (`.zed`).

> **Note:** This is a community-maintained plugin, not affiliated with or endorsed by AuthZed.

## Features

- Full PSI parser for the SpiceDB schema language, including composable schema
  syntax: `partial` blocks, `...partial` splats, `use` flags, `import`,
  caveats, `type:*` wildcards, `type#relation` subject references
- Go to Definition (Ctrl+Click) for:
  - type references → `definition`
  - `type#relation` subject references → the relation in that type
  - arrow targets (`rel->perm`, `rel.any(x)`, `rel.all(x)`) → the member in
    every target type of the base relation
  - local identifiers in permission expressions → relations/permissions of the
    enclosing definition, including members inherited via `...partial` splats
  - `with caveat_name` → the caveat declaration
  - `...partial_name` → the partial declaration
- Find Usages for definitions, partials, relations, permissions, and caveats
- Syntax and semantic highlighting with distinct colors per declaration kind
- Brace matching and comment support

All `.zed` files in the project are indexed — schemas can live in any
directory layout, including nested `compose/<domain>/` folders.

## Supported IDE versions

Any JetBrains IDE based on the IntelliJ Platform **2024.3 (build 243) or newer** —
IntelliJ IDEA (Community/Ultimate), GoLand, WebStorm, PyCharm, etc.

## Installation

### From a Release (recommended)

1. Download `intellij-spicedb-plugin-<version>.zip` from the
   [Releases](https://github.com/jeanlouhallee/intellij-spicedb-plugin/releases) page
2. In your IDE: **Settings → Plugins → ⚙️ → Install Plugin from Disk...**
3. Select the downloaded zip
4. Restart the IDE

### From Source

```bash
./gradlew buildPlugin
```

The zip is produced at `build/distributions/intellij-spicedb-plugin-<version>.zip` —
install it the same way (Install Plugin from Disk).

### Run a sandbox IDE

```bash
./gradlew runIde
```

## Development

The parser and lexer are generated by
[Grammar-Kit](https://github.com/JetBrains/Grammar-Kit) from
`src/main/grammars/SpiceDb.bnf` and `src/main/grammars/SpiceDb.flex` into
`src/main/gen/` (gitignored, regenerated automatically before compilation).

```bash
./gradlew generateParser generateLexer   # codegen only
./gradlew test                           # parsing + resolution tests
```

## Requirements

- IntelliJ IDEA 2024.3+
